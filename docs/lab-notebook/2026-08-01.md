## App integration build failure

The first OTLP/HTTP integration build could see `OtlpHttpTraceExporter` but not

## Timestamp round-trip failure

The first generated-ledger test stored `Date` using JSON's ISO-8601 strategy. A
fractional timestamp did not round-trip exactly. Because delivery latency will be
calculated from these records, approximate equality is inappropriate. The ledger
now stores `endedAtUnixNanoseconds` as an integer.

## Reconciliation CLI compiler failures

1. `Data.split(separator:)` was ambiguous between `Sequence` and `Collection`.
2. Converting slices with `.map(Data.init)` triggered a compiler diagnostic
   failure.

Converting to `[UInt8]` and using an explicit closure (`map { Data($0) }`) built
successfully.
